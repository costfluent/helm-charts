The Costfluent agent reports cluster {{ .Values.agent.clusterID | quote }} to {{ .Values.agent.apiEndpoint }}.

The first report arrives about two minutes after the pod starts, and the cluster then shows under
Settings > Integrations > Kubernetes. Costs appear after the next nightly processing run.

Check the agent:

  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/instance={{ .Release.Name }} -f

For clusters without a cloud bill, set node rates with the costfluent.com/*-hourly-rate node
annotations or in the cluster's settings. https://docs.costfluent.com/connect/kubernetes
